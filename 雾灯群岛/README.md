# 雾灯群岛

Steam 单人自由探索冒险的 Unity 6 原型工程。首个垂直切片只验证一个循环：在晨湾港接取修塔线索，驾船前往潮汐浅滩，完成探索后返回港口。

## 当前可玩内容

- 运行时生成的晨湾港灰盒场景：码头、房屋、地标路牌、动态灯火、潮蚀岩、灯塔与雾海。
- 第三人称角色移动与镜头控制；镜头遇到房屋等实体遮挡时会向角色收近。
- 程序生成的海风与潮声环境音；标题与暂停时自动静音，并受总音量设置控制。
- 港口任务告示与交互提示，展示试玩版的首个任务目标。
- 可驾驶的“晨鹱号”、晨湾港与潮汐浅滩的靠岸点，以及上下船流程。
- 首条可完成任务：接取灯塔委托、在潮汐浅滩拾取棱镜零件、返港交付给管理员艾琳。
- 使用本地存档保存任务阶段和“勘测帆”升级；交付棱镜后会点亮晨湾港灯塔，并可向船匠乔恩领取升级。
- 成功靠岸下船时记录码头；重开后角色和小船一起从上次靠岸码头继续。航行途中退出会回到上次靠岸码头；旧存档默认回晨湾港，新档会清除码头记录。
- 任务指引会随阶段更新 HUD 目标、罗盘菱形和海图标记；目标在身后时罗盘会给出左右后方提示。
- 潮汐浅滩含有一个三步环境谜题：按西→中→东点亮潮汐信标，才会开启棱镜祭台；已点亮信标会跨重启保存。
- 试玩版已具备三条顺序任务：灯塔棱镜、失落航图、风暴透镜；每条都由港口 NPC 接取、前往潮汐浅滩探索并返港交付。艾琳和乔恩在可见距离内有姓名与身份牌，打开对白或菜单时自动隐藏。
- 完成第三条任务后会明确提示试玩版主线结束；玩家仍可继续自由探索并收集发现物。
- 四个不影响主线的可保存探索发现物，分布在晨湾港与潮汐浅滩；艾琳和乔恩会根据发现进度提供地点传闻，探索笔记也为未找到的物品提供可选的环境方位线索。日志、罗盘、贝壳与护符各有不同的灰盒轮廓和颜色；港口两件物品有木箱和木座支撑，浅滩的贝壳旁有浅水洼，护符置于旧石台。集齐四件后返港找艾琳，可永久解锁导航台旁可阅读的旧航线陈列；续档后仍会显示。
- 可随时打开的任务日志，列出三条任务的阶段、下一步线索和探索发现计数。

## 打开方式

1. 使用 Unity Hub 安装 **Unity 6.0 LTS**，并选择 Windows Build Support。
2. 在 Hub 中点击“Add”，选择此目录。
3. 打开 `Assets/Scenes/Main.unity`，点击 Play。

首次打开时，工程会自动启用 Standalone 的新版 Input System；若 Unity 提示重启编辑器，请确认重启后再进入 Play Mode。

## 操作

- `WASD`：移动
- 鼠标：旋转视角
- `Shift`：奔跑
- `E`：与附近对象交互
- 登船后 `W/S`：加速/减速；`A/D`：转向；HUD 显示航速与目标码头距离，进入码头范围且航速低于 1.2 m/s 后按 `E` 下船。登船镜头会先朝向船头。
- 通用手柄：左摇杆移动/航行和转向，右摇杆观察，按下左摇杆奔跑，`A` 交互、登船或靠岸。
- `Esc` 或手柄 `Menu`：暂停；可调整总音量、视野角、镜头速度（鼠标与右摇杆共用 50%–200%）、全屏/窗口及帧率模式（默认 60 FPS 限制，或垂直同步）。手柄用十字键选择和调整、`A` 确认、`B` 返回。设置保存在本机，重启后恢复；窗口尺寸也会在切回窗口模式时恢复。
- 暂停菜单可选择“新档试玩”；系统会二次确认，再清除任务、升级、谜题与探索发现并重新开始。
- 与艾琳、乔恩交互时会显示可推进的角色对白；使用 `E`、Space 或手柄 `A` 继续。
- 启动后先显示标题界面；按 Enter、手柄 `A` 或点击“开始探索”（有进度时显示“继续探索”）进入晨湾港。按 `N`、手柄 `Y` 或点击“新档试玩”可在二次确认后清除进度，保留音量和画面设置。
- 顶部罗盘显示角色方位与当前任务目标的相对方向，减少航行时对精确箭头的依赖。
- `Esc`：释放鼠标
- `M` / 手柄 `View`：打开区域地图；地图会显示你、小船和当前任务目标，并暂停游戏。按 `M`、`View`、`Esc`、手柄 `B` 或点击“关闭”返回。
- `J` / 手柄 `Y`：打开日志，查看任务进度或已找到的探索线索；用 `Tab` / 手柄 `RB` 切换页面，按 `J`、`Y`、`Esc` 或手柄 `B` 关闭。

## 本周完成定义

在编辑器中能够从港口出生点自由移动，靠近告示牌时看到“前往潮汐浅滩”的任务提示；随后登上晨鹱号并驶向潮汐浅滩码头。这分别是第 1、2 周灰盒验收的一部分。

## Windows 构建

验证通过后，在 Unity 顶部菜单选择：

- `Foglight Isles > Build Windows Demo (Development)`：输出到 `Builds/Windows/FoglightIslesDemo.exe`，用于自动验证与本地调试。
- `Foglight Isles > Build Windows Demo (Release Candidate)`：输出到 `Builds/ReleaseCandidate/FoglightIslesDemo.exe`，关闭 Unity Development 标记，作为 Steam 上传前的候选包。

需要发送 Windows 试玩包时，在项目根目录运行 `./Tools/PackageWindowsDemo.ps1`。脚本将运行必需文件及试玩说明、反馈模板、试玩和反馈收集入口打包到 `Builds/Distribution/FoglightIslesDemo-Windows-0.2.14.zip`，自动排除验收截图与 Unity 的 `DoNotShip` 调试目录。0.2.14 沿用 0.2.13 的游戏程序集，只更新试玩日志留存与反馈收集；所以二者标题页构建编号相同，反馈中还需填写 `BUILD_INFO.txt` 首行的包版本。解压 ZIP 后双击 `PLAYTEST_START.cmd` 可使用独立试玩进度；每次重开会把上一轮 `playtest.log` 改名为 `playtest-*.log`，保留跨进程试玩日志。F12 截图保存在本机 `AppData/LocalLow/Foglight Isles/Foglight Isles Demo/Screenshots`。海图或日志打开时按手柄 Menu 可转入暂停，按 B 从暂停返回游戏。退出游戏并填写 `FEEDBACK_TEMPLATE.md` 后，双击 `COLLECT_FEEDBACK.cmd` 可将构建信息、反馈表、当前与此前的试玩日志和这些日志记录的 F12 截图打成同目录 ZIP；此操作不会上传数据，发送前请检查内容。直接运行 `FoglightIslesDemo.exe` 则使用常规进度。发布到 Steam 前仍需完成实体输入、显示模式和目标设备验收。

构建目录已被 Git 忽略。
