# Steam 商店页初稿

## 名称

《雾灯群岛》 / *Foglight Isles*

## 短描述

驾驶一艘可升级的小船，在迷雾群岛之间发现失落航线、修复灯塔，并决定港口的人们将如何继续远航。

## 关于此游戏

浓雾遮住了群岛的航线，也遮住了每个人不愿提起的往事。作为晨湾港的新任探索者，玩家将从一艘小船和一束灯火开始，接取港口委托、循着地标与灯塔光束驶向未知岛屿，并将发现带回不断变化的港口。

### 试玩版特色

- 驾驶“晨鹱号”从晨湾港穿越迷雾，靠岸并徒步探索潮汐浅滩。
- 通过环境线索完成潮汐信标谜题，取得修复灯塔的关键棱镜。
- 认识港口管理员艾琳与船匠乔恩，完成三条相互衔接的探索委托。
- 使用键鼠或手柄游玩；可调整音量和视野角，任务与升级自动保存。
