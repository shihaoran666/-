# UI 布局验证记录

## 2026-11-11：安全区与高分辨率缩放

- 范围：标题界面、游戏 HUD、目标罗盘。
- 实现：各界面经 `SafeGuiLayout` 使用 `Screen.safeArea`，并以 1280×720 为参考分辨率、最高 150% 缩放。
- 640×360 图形抓帧：标题、开始/新档/退出按钮和两类输入提示均完整可见，没有裁切。
- 1920×1080 图形抓帧：标题缩放后仍完整；游戏 HUD、罗盘、NPC 名称牌和底部操作提示没有重叠或出界。
- 回归：更新后的候选版运行 `-verify-keyboard-journey` PASS，覆盖标题、告示牌、登船、靠岸下船、石碑、信标与棱镜。

限制：Windows 桌面环境的 `Screen.safeArea` 通常覆盖全屏，因此实际电视过扫描、主机系统安全边距和实体手柄可读性仍需在目标设备上验收。
