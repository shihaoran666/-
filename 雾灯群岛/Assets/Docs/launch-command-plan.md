诊断必须回答的关键问题：

1. 实际可玩时长多少？内容密度够不够撑住 Steam？
2. 「动机 → 行动 → 回报 → 新动机」链条在哪一环断？
3. 第一次玩的陌生人会不会在港口迷路、海上找不到岛？
4. 手感参数是否在舒适区间？
5. **原始需求是「自由探索类主机游戏」，现在这套 PC 键鼠设计在主机上哪里会直接出问题？**
6. 现在能不能拿去给陌生人试玩？距离「让人愿意付钱」差什么？
