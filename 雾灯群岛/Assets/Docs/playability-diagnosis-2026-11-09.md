# 可玩性诊断报告（2026-11-09）

> 结论：**3/10。工程质量远超内容量。自动化验证 70 次 PASS，真人试玩 0 次。**
> **能不能给陌生人试玩：技术能，设计上不该现在发。**
> 一句话：这套流程一直用「证明代码能跑」回避「证明游戏好玩」。

## 一、内容量：严重不足，差 3–5 倍

- 不是「7–10 个房间」，是 **2 个开放方块空地**。`GameBootstrap.cs:154` 港岸是 (34,1,28) 立方体，`:177` 浅滩是 (38,1,32) 立方体，相距 94 单位。
- **可进入室内 = 0**。`BuildHouse(:403-408)` 只生成「立方体+屋顶」，无门无内部。港务办公室/修船屋/船匠铺都是实心方块。README 说的「房屋」是装饰。
- **跨海航程约 7 秒**（船 max 11 m/s、accel 4，63.3 米 = 2.75s 加速 + 4.2s 巡航）。装勘测帆后 7.1 秒，升级体感差 0.1 秒。
- 实际时长：熟练 13–18 分钟，首玩 20–30 分钟。`core-design.md:12` 承诺 30–45 分钟，实际在下限之下，且 60% 以上是重复直线往返。
- 三条任务结构同构（`QuestState` / `SurveyChartQuest` / `StormSignalQuest`），第 2、3 条只是把「棱镜」换成「航图」「透镜」，无独立机制。玩家 30 秒内就会识别出重复。
- 地图总面积 `MapOverlay.cs:153-155` 映射 x∈[-25,25]、z∈[-110,28] = 50×138 单位。

## 二、核心循环：机械闭合，情感上断在「回报」

- **「发现航线」这个动词不存在。** 雾密度 0.009（`GameBootstrap.cs:132`），94 米处仍有约 49% 可见度；罗盘+海图直指目标。唯一目的地，一条航线。
- **修灯塔的奖励玩家看不见**：`_lighthouseLight.range = 24f`（`GameBootstrap.cs:417`），而跨海 94 米。灯光在海上永远不可见。
- 「每次返航改变港口」只落地为 3 个 SetActive：灯塔(`:573-575`)、导航台航图(`:576`)、信号桅杆(`:577-579`)。全部是道具开关。
- **根本原因：`ProgressStore.cs:9-13` 只有 5 个任务阶段键 + 4 个发现物布尔值，没有任何 NPC 关系/港口繁荣度状态。** 这条承诺在当前数据结构里不可能成立。NPC 台词是按阶段查表的 switch，不是关系累积。
- 自由探索兑现约两成：4 个发光小物件 + 4 条笔记文本 + 两句台词，无玩法功能。

## 三、引导：结构对，但谜题被 HUD 自我抵消（关键发现）

- **`TideBeaconPuzzle.cs:16` `CurrentTarget => _beacons[_progress]`，被 `GameBootstrap.cs:606` 与 `:675` 设为引导目标。**
  意思是：点亮西侧后罗盘立刻指向中央，再指东侧。石碑「西→中→东」线索、方位辨识、走错重置，全被顶部菱形跳过。
  **唯一谜题被自己的引导解掉了。** 技术上符合「禁止世界箭头」，功能上就是那个箭头。
- 港口找告示牌不会迷路（出生点 6 米 + 罗盘），海上不会迷路——但也因此没有探索。
- **无教学**：`StartScreen.cs:148` 只有一句欢迎语，J/M 键进游戏后无提示（只在标题页第三行小字 `StartScreen.cs:110`）。
- 兜底部分有：掉海 `RecoverIfBelowSea(:206-218)` OK；**但船无世界边界**，可驶入 200×200 海面外虚空，无召回提示，唯一退出是 Esc→新档（清进度）= 软锁风险。

## 四、手感：角色合格，船有三个反直觉设定，其中一个是致命的

- PlayerController 合格：走 4.2/跑 6.4、0.12°/px、pitch -15~55、标准第三人称相机+碰撞收近。
- **致命：`BoatController.cs:66` 转向力随速度提升（静止仅 25%=13°/s），而 `:83` 靠岸要求速度<1.2。**
  即「要求你慢下来，慢下来却不听使唤」。叠加 11 m/s 转弯半径 12.1 米 vs `DockingPoint.cs:7` 判定半径 4 米；松油门 drag 1.4 需滑行 43 米才停。
  **首次试玩 20 分钟会大量耗在跟船搏斗，而不是看雾里的灯塔。**
- 手柄左摇杆无死区（`PlayerController.cs:193`、`BoatController.cs:47`）；键盘与手柄输入相加——手柄漂移会让角色自己走，Steam Deck/老手柄必现。无失焦暂停（`AmbientSoundscape.cs:23` 只在菜单暂停）。

## 五、「桌面抓帧超时」= 用测代码替代了测游戏

- `milestones.md:42、:72、:129、:149、:155` 反复出现。全部视觉证据来自游戏自身 F12/`-capture-*`，外部工具无法接管窗口。
- 后果：所有「可读性 PASS」都是静态帧、由写文案的人自评；所有「驾驶 PASS」都是虚拟键盘/虚拟手柄，不会犹豫不会冲过头。
- 统计：`PASS` 70 次，`真人/试玩/实体手柄` 66 次——几乎每条都以「仍待真人」结尾。
- 59.8 FPS 只是撞到自设的 60 帧上限（`GameBootstrap.cs:48`），不提供优化余量信息。1% low 55.5–58 健康。真正未解决是 GC 4.2–5.5 KB/帧且 release 测不了。

## 六、平台定位：主机适配度约 0

- 构建只有 StandaloneWindows64（`BuildWindowsDemo.cs:51`）；InputSystem 只对 Standalone 启用（`InputSystemProjectSetup.cs:24-27`）；XboxOne/PS/Switch 配置全空默认值。
- 主机上会直接出问题的：
  1. `PrototypeHUD` 全套 IMGUI 固定像素（fontSize 16、`Rect(16,16,558,166)` 无 GUI.matrix 缩放），字幕 17px、标题页 54/20/16 全固定 → 4K 电视 3 米外不可读；
  2. 全工程 0 处 `Screen.safeArea`，HUD 贴边 y=16 / height-45 会被 TV overscan 切掉（认证硬要求）；
  3. `PrototypeHUD.cs:83-84` 硬编码「WASD 移动 · 鼠标观察 · Shift 奔跑」，`StartScreen.cs:110` 同 → 主机手柄玩家一直看到 WASD；
  4. 鼠标是默认交互模型（Esc/左键锁光标、GUI.Button 靠点）；
  5. 无死区/无断连/无失焦暂停；
  6. PlayerPrefs 隐式单档，无损坏/无空间/多云存档处理（认证要求）；
  7. 全中文硬编码无本地化层；
  8. IMGUI 中文字形靠系统字体回退，主机封闭字体环境可能显示方块——PC 永远不会暴露。
- **建议：不要现在做主机工程。分三层**：
  - 现在（≈0 成本）：UI 改相对字号 + `GUI.matrix` 统一缩放（抄 `MapOverlay.cs:63` 范式）、加 safeArea 内缩、操作提示按当前设备动态生成。
  - 下次大改：加死区/输入不相加/失焦暂停（PC 上也立刻改善，纯赚）。
  - 验证通过后：IMGUI→Canvas、存档抽象、本地化。

## 八、距「让人愿意付钱」还差什么（按重要性）

1. 内容量差 3–5 倍（至少 5–6 个岛、2 个有室内、每链独立机制）；
2. 返航改变港口必须真发生（NPC 记忆、港口物理长大、至少 1 个二选一分支）；
3. 航海成为玩法（航程拉到 60–90 秒、雾真正遮蔽、先改 lighthouse range 24f）；
4. 靠岸手感；
5. 视听（灰盒 + 一段 18 秒正弦波，商店页要求的 5 张截图一张都拍不出来）。
