# 《雾灯群岛》核心设计（一页版）

## 玩家承诺

玩家驾驶一艘可逐步升级的小船，在浓雾笼罩的群岛中依靠地标、光束与传闻主动发现航线；每次返航都会让港口与人物关系发生可感知的变化。

## 垂直切片

- 地点：晨湾港与潮汐浅滩。
- 目标：取得失修灯塔的棱镜零件，并带回港口。
- 核心机制：移动、对话/交互、航行（第 2 周）、环境探索、任务追踪与存档（第 3–4 周）。
- 体验时长：30–45 分钟。

## 设计边界

- 使用半开放海域与手工设计的岛屿；不制作无缝开放世界。
- 指引采用“任务日志 + 罗盘方向 + 远景地标”，禁止常驻的精确世界箭头。
- 战斗不进入第一阶段；探索、航行和环境谜题优先。
