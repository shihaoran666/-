# NPC 剪影候选交接

- 基线：`main` 的 Windows Demo 0.2.4 源码；本分支未生成新构建。
- 目标：让艾琳和乔恩在港口雾中有不同人形轮廓，减少只靠名牌识别 NPC 的情况。
- 修改：仅 `雾灯群岛/Assets/Scripts/GameBootstrap.cs`。艾琳保留灯塔徽记，身体改深蓝，加入高帽与浅色卷册；乔恩身体改深褐，修船工具有锤头，加入扁帽与小腰灯。两个 NPC 根对象、位置、交互组件、名字牌及任务回调均未更改。
- 物件预算：每人共 5 个 Primitive（含原胶囊体）；新增装饰无碰撞。腰灯复用现有发光材质，不增加实时 Light。

## 已检查

- `git diff --check` 无空白错误。
- 静态核对新增装饰只挂到对应 NPC 根对象；交互与导航引用仍指向原根对象。
- 未运行 Unity 构建、截图或真人测试；视觉对比和编译必须由集成者确认。

## 集成者验收

1. 审查本分支 diff 后合入主工程，运行 Unity 6.0 Windows 构建与 `-verify-quest-loop`、`-verify-new-save`；确认对话和任务推进没有回归。
2. 在晨湾港从玩家出生点及约 11 米外截 1280×720、640×360 图；遮住名牌后比较两个人形轮廓是否能区分，并检查卷册、锤头和腰灯未被身体遮蔽。
3. 玩家走近两人，确认交互选择、碰撞范围、路线引导与过去一致；在固定截图条件下比较新增 6 个装饰 Primitive 的性能影响。

## 风险

- 颜色与帽子尺寸仅按代码估算，受雾、视角和灯光影响，尚无实机视觉证据；若不清晰，优先调高帽/扁帽轮廓和卷册明度，不扩大交互范围。
- 旧的艺术方案文档部分判断可能过时，本候选只针对 NPC 造型，不代表其他美术问题已验证。
